# VibeHelper iOS

Public Flutter iOS client mirror and GitHub Actions (`macos-latest`) unsigned `.ipa` build workflow for AltStore / SideStore installation.

- Targets `client-app/` + `scripts/patch_ios.py` (`VibeIslandWidget.appex` Live Activity extension + 9 custom pixel-pet fonts).
- Produces unsigned `release/vibehelper-client-ios.ipa` and `release/manifest.json` under the `ci-latest` GitHub Release and workflow artifacts.
